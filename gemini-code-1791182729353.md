# AJAR Document Manager

A lightweight, single-file React web application designed to streamline the creation and management of business documents. It handles the complete workflow of generating Quotations, converting them to Invoices, and finally creating Delivery Notes, all while keeping track of document numbers and customer details.

## 🚀 Key Features

*   **Seamless Document Workflow:** Instantly generate an Invoice from a Quotation, and a Delivery Note from an Invoice, with data carrying over automatically.
*   **Smart Auto-Numbering:** Automatically generates sequential document numbers (e.g., `2026/Q/Ajar/1`, `2026/Inv/Ajar/1`) and remembers the sequence for your next project.
*   **Customer Management:** Built-in customer list with a "Quick Add" feature and dropdown auto-fill to speed up data entry for repeat clients.
*   **Address Book:** Manage multiple business addresses and set a default address to appear on your documents.
*   **Digital Signatures:** Draw a signature directly on the canvas or upload an image file. Easily toggle the saved signature onto Invoices and Delivery Notes before printing.
*   **Project History:** Automatically bundles related Quotations, Invoices, and Delivery Notes together in a History tab for easy retrieval of past jobs.
*   **100% Local Storage:** All data (customers, addresses, signatures, and document history) is securely saved in your browser's local storage. No database or internet connection required after the initial load.
*   **Print & PDF Ready:** Optimized with CSS media queries to hide buttons and menus during printing, ensuring a clean, professional A4 document.

## 🛠️ Technologies Used

*   **React 18** (via CDN for single-file execution)
*   **Tailwind CSS** (for rapid, responsive styling)
*   **HTML5 Canvas** (for signature drawing)
*   **Browser LocalStorage** (for data persistence)

## 📖 How to Use

The application is divided into several tabs for easy management:

1.  **Edit Data:** The main workspace. Select a customer, enter item descriptions, quantities, and prices (in MVR). From here, you can preview and generate your documents.
2.  **Customers:** Add, edit, or remove client details. Saving them here makes them available in the auto-fill dropdown on the Edit tab.
3.  **Addresses:** Store multiple business addresses. Set one as your "Default" to have it automatically populate the header of your generated documents.
4.  **Signature:** Draw your signature using a mouse/touchscreen, or upload a clear PNG/JPG of your signature. Once saved, a toggle will appear on your Invoices and Delivery Notes to append it above the "Authorized Signatory" line.
5.  **History:** View your previously generated document bundles. Clicking on a bundle number will load the saved Quotation, Invoice, and Delivery Note for that specific job.

## 💻 Installation & Setup

Because this is a single-file application, there is no complex build process, server setup, or installation required.

1.  Download or copy the provided `index.html` file.
2.  Double-click the file to open it in any modern web browser (Chrome, Edge, Firefox, Safari).
3.  Ensure you have an active internet connection the very first time you open it so the browser can cache the React and Tailwind libraries.

## 🖨️ Printing & Saving as PDF

1.  Generate your desired document (Quotation, Invoice, or Delivery Note).
2.  Click the large green **"Print / Save PDF"** button at the top of the document preview.
3.  In your browser's print dialog, set the destination to your physical printer or select **"Save as PDF"**.
4.  *Tip: Ensure "Background graphics" is enabled in your print settings to retain the table colors and borders.*
